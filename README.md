# SmartMoney Academy

Next.js application for SmartMoney Academy learning content and member experiences.

## Getting Started

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Core Scripts

- `npm run dev` — start local development server.
- `npm run lint` — run ESLint.
- `npm run build` — run production build checks.
- `npm run health:check` — run a consolidated engineering health check.
